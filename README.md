# Department Enquiry Bot AI Agent

## About the Project

The Department Enquiry Bot is an AI-powered assistant designed to help Computer Engineering students access department-related information.

## Features

* Faculty and HOD information
* Subjects and syllabus
* Class timetable
* Examination and practical information
* Laboratory details
* Assignments and projects
* Internship and placement information
* Department notices and events
* Student queries through an AI chatbot

## Technologies Used

* Google AI Studio
* HTML, CSS and JavaScript (if used in the project)
* Gemini API (if integrated)
* Other technologies used in the project
